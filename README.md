# Хранитель приключений

Телеграм-бот для сообщества «Рыцари НРИ». Ведёт сказ в общем чате или в личке: показывает сцену, ставит голосование, затем последствия и картинку.

В группе бот ждёт срок голосования. В личке и в тестовом режиме отвечает сразу после голоса.

## Как устроен сценарий

Папка — одна **история**. У истории может быть несколько **версий** (чтобы меньше спойлеров):

```
adventures/primer/adventure.yaml          # версия default
adventures/primer/tale.yaml               # общее название (необязательно)
adventures/primer/variants/alt/adventure.yaml
adventures/primer/images/oak.png
```

```yaml
title: Перекрёсток у старого дуба
vote_minutes: 60
start: crossroads
scenes:
  crossroads:
    text: Ночь, старый дуб и три дороги.
    image: images/oak.png
    choices:
      - label: Свернуть в лес
        next: forest
      - label: Идти к огням деревни
        next: village
  village:
    text: В деревне не спят.
    choices: []
```

- `start` — первая сцена. Бот показывает её и сразу открывает голосование.
- Вариант выбора — подпись в опросе (до 100 знаков) и id следующей сцены.
- Скиллчек (необязательно): `chance: [min, max]` — диапазон шанса успеха в процентах
  (каждый бросок берёт свежий порог внутри диапазона, не константу) и `fail` — сцена
  при провале; `next` — при успехе. Пути обязаны быть разными. Игрокам не показывается;
  в личном `/test` бот пишет, где чек, какой диапазон и что выпало.
- Выборов от 2 до 10. Ноль — конец сказа. Один — бот идёт дальше без опроса.
- Ничья или ноль голосов — берётся вариант, который в файле стоит раньше.
- Картинка необязательна: png, jpg, webp или gif внутри папки версии.
- Сказитель добавляет или убирает версии в `variants/<id>/`. События версий могут совпадать частично или расходиться полностью.

Пример: `adventures/primer` (есть и `default`, и `alt`).

## Генератор

Сейчас — в консоли, из корня проекта:

```
python -m generator
```

Спрашивает название, длительность, сцены и варианты и пишет `adventures/<папка>/adventure.yaml`. Картинки кладутся в папку по путям из файла. Папку можно заархивировать и прислать боту.

Позже тот же файл будет собирать страница на сайте: форма отдаёт zip, бот его уже принимает.

## Бот

Нужны Python 3.11, токен [@BotFather](https://t.me/BotFather) и числовой id ведущего.

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python -m khranitel
```

В `.env`: `TELEGRAM_BOT_TOKEN` и `ADMIN_IDS` (несколько id через запятую).
Необязательно `ADMIN_TOKEN` — токен тестового режима; если пусто, бот сам создаст и напечатает при старте.

### Команды в группе

- `/begin` — голосование: три условно случайные истории (недавние из прошлой и позапрошлой сессии вне кандидатов на это и следующее голосование)
- `/begin имя` — сразу эта история (ведущий)
- `/retell` — пересказать только что оконченную
- `/status` — сколько осталось
- `/stop` — оборвать (ведущий); бот сокрушается
- `/spoiler` — голосование за другую версию текущей/недавней истории
- `/adventures` — список историй и версий
- `/help` — список команд

### Команды в личке

- велком при первом сообщении и `/start`
- `/begin` — те же три истории, но ответ сразу после голоса
- `/retell`, `/status`, `/stop`, `/help`
- `/spoiler` в личке не работает и в `/help` не показывается
- `/test <админ-токен>` — тестовый режим: пункт «↩ Назад» в опросах, ответ сразу

В конце сказа бот предлагает `/retell` и спрашивает: «а может было по-другому?»

Новый сценарий ведущий присылает в личку: `adventure.yaml` или zip. Другие версии — папки `adventures/<история>/variants/<id>/`.

В одном чате или теме форума одновременно один сказ. В сообществах с темами бот отвечает в ту же тему, откуда вызвали команду.

Срок голосования в группе зависит от числа участников (примерно минута на человека, не короче ~1.5 мин и не дольше `vote_minutes` сценария). Если проголосовали все ожидаемые участники — опрос закрывается раньше дедлайна. Опросы не анонимные, чтобы бот видел голоса и мог закрыть досрочно. После перезапуска открытое голосование подхватывается.
