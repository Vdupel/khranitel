# Хранитель приключений

Телеграм-бот для сообщества «Рыцари НРИ». Ведёт одно общее приключение в чате: показывает сцену, ставит голосование на время, по окончании пишет, что выбрало большинство, описание последствий и картинку, затем открывает следующее голосование.

## Как устроен сценарий

Папка с именем приключения:

```
adventures/primer/adventure.yaml
adventures/primer/images/oak.png
```

```yaml
title: Перекрёсток у старого дуба
vote_minutes: 60
start: crossroads
scenes:
  crossroads:
    text: Ночь, старый дуб и три дороги.
    image: images/oak.png
    choices:
      - label: Свернуть в лес
        next: forest
      - label: Идти к огням деревни
        next: village
  village:
    text: В деревне не спят.
    choices: []
```

- `start` — первая сцена. Бот показывает её и сразу открывает голосование.
- Вариант — подпись в опросе (до 100 знаков) и сцена, которая наступит, если он победит. Текст и картинка этой сцены и есть последствия.
- Вариантов от 2 до 10. Ноль — приключение кончается. Один — бот идёт дальше без опроса.
- Ничья или ноль голосов — берётся вариант, который в файле стоит раньше. Бот так и пишет.
- Картинка необязательна: png, jpg, webp или gif внутри папки сценария.

Пример уже лежит в `adventures/primer`. Голосование в нём — 2 минуты, чтобы проверить бота.

## Генератор

Сейчас — в консоли, из корня проекта:

```
python -m generator
```

Спрашивает название, длительность, сцены и варианты и пишет `adventures/<папка>/adventure.yaml`. Картинки кладутся в папку по путям из файла. Папку можно заархивировать и прислать боту.

Позже тот же файл будет собирать страница на сайте: форма отдаёт zip, бот его уже принимает. Отдельного формата для сайта не будет.

## Бот

Нужны Python 3.11, токен [@BotFather](https://t.me/BotFather) и числовой id ведущего.

```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
.venv\Scripts\python -m khranitel
```

В `.env`: `TELEGRAM_BOT_TOKEN` и `ADMIN_IDS` (несколько id через запятую).

Бота добавляют в чат сообщества. Ему достаточно права писать сообщения. Команды:

- `/adventures` — список сценариев
- `/begin primer` — начать в этом чате
- `/status` — сколько осталось
- `/stop` — прервать

Новый сценарий ведущий присылает боту в личку: `adventure.yaml` или zip, внутри которого он лежит вместе с картинками. В чате после этого — `/begin` и имя файла без расширения.

В чате одновременно идёт одно приключение. Срок голосования бот держит сам: опрос Телеграма сам закрывается только в пределах десяти минут, а сценарию можно поставить хоть сутки. После перезапуска открытое голосование подхватывается.
